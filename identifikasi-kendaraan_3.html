Hubungkan ke Database (Supabase, gratis) ›
  1. Buat akun gratis di supabase.com, lalu buat New Project (pilih region terdekat, mis. Singapore).
  2. Di project Anda, buka SQL Editor, tempel skrip berikut, lalu jalankan (Run) untuk membuat tabel kendaraan: 
    create table kendaraan (
  id uuid primary key default gen_random_uuid(),
  kategori text not null,
  merk text not null,
  model text not null,
  type text,
  jenis text,
  tahun int,
  no_rangka text,
  no_mesin text,
  plat_nomor text,
  km_saat_ini int,
  created_at timestamptz default now()
);

alter table kendaraan enable row level security;

create policy "izinkan akses anon (prototipe pribadi)"
on kendaraan for all
using (true)
with check (true);
    Policy ini mengizinkan akses penuh lewat anon key — cukup aman untuk prototipe pribadi yang tidak dibagikan publik, tapi bukan untuk aplikasi banyak pengguna.
  3. Buka Project Settings › API, salin anon public key project Anda, lalu tempel di bawah ini (Project URL sudah diisi otomatis).
  4. Tabel tambahan untuk modul Work Order (sudah dijalankan — disertakan di sini sebagai referensi, mis. untuk setup ulang di project Supabase lain): 
    create table work_order (
  id uuid primary key default gen_random_uuid(),
  kendaraan_id uuid not null references kendaraan(id) on delete cascade,
  task_key text,
  judul text not null,
  deskripsi text,
  status text not null default 'open' check (status in ('open','proses','selesai','batal')),
  prioritas text not null default 'normal' check (prioritas in ('rendah','normal','tinggi')),
  tanggal_target date,
  km_target int,
  tanggal_selesai timestamptz,
  km_saat_selesai int,
  parts_terpakai text,
  biaya_part numeric,
  biaya_jasa numeric,
  bengkel text,
  catatan text,
  created_at timestamptz default now(),
  updated_at timestamptz default now()
);

create index work_order_kendaraan_idx on work_order (kendaraan_id);
create index work_order_status_idx on work_order (status);

alter table work_order enable row level security;

create policy "izinkan akses anon (prototipe pribadi)"
on work_order for all
using (true)
with check (true);
URL dan key disimpan hanya di browser perangkat ini (localStorage), tidak dikirim ke pihak lain selain Supabase Anda sendiri.

Support / Konsep Aplikasi

Konsep Aplikasi: Auto Maintenance Repair Management

Ringkasan strategi dan arah pengembangan AutoPrima. Dokumen lengkap & dapat diedit ada di Claude Docs terpisah.

Ringkasan & Tujuan

AutoPrima adalah sistem manajemen perawatan kendaraan pribadi (mobil/motor) yang mengadopsi pendekatan reliability-centered maintenance ala industri penerbangan — bukan sekadar pencatatan servis bengkel, melainkan program perawatan terstruktur untuk menjaga kendaraan tetap andal, aman, dan layak jalan.

Setiap kendaraan diberi identitas lengkap (kategori, model, type, jenis, merk) dan riwayat tercatat rapi per komponen, sehingga keputusan servis didasarkan pada data (KM, usia part, siklus pemakaian), bukan perkiraan.

Asumsi yang Digunakan
  • Pengguna: individu pemilik kendaraan pribadi, bisa mengelola beberapa kendaraan dari satu akun.
  • Cakupan kendaraan: mobil dan motor pribadi, dikelompokkan berdasarkan kategori, model, type, jenis, dan merk.
  • Kepatuhan regulasi: mengacu ke UU LLAJ dan Peraturan Polri untuk kelaikan jalan; kerangka ISO 9001/14001 dan gaya penerbangan (FAA/EASA/CASR) diadopsi sebagai metodologi, bukan kewajiban sertifikasi.
  • Konektivitas & data: multi-device, terhubung ke database gratis (Supabase).

Modul & Fitur Utama
  1. Identifikasi Kendaraan — profil lengkap per kendaraan (modul yang aktif di tab Home).
  2. Maintenance Program 5 Tahun — peta jangka panjang perawatan besar & penggantian part utama.
  3. Maintenance Plan 1 Tahun — turunan tahunan dari program 5 tahun.
  4. Jadwal Maintenance Activity — mingguan/bulanan/3-bulanan/5-bulanan, dipicu KM/usia/cycle.
  5. Reliability Control Program — pelacakan keandalan tiap part/komponen.
  6. Riwayat & Log Perawatan, Control & Monitoring, Manajemen Biaya, Informasi Spare Part.
  7. Toolkit Analisis (PDCA, FMEA, PICA, 5W1H, fishbone) & Rekomendasi Aksi preventive/predictive.
